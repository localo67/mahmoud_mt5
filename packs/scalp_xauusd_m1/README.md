# Pack scalp XAUUSD (or)

Meme idee que `scalp_eurusd_m1`, avec des seuils plus larges a cause du spread or.

- Semaine forex : dimanche 23h → vendredi 23h heure de Paris (17h New York)
- Spread max 0.40 (40 points de 0.01). Si ton courtier est plus cher : le bot ne trade pas. C'est voulu.
- Objectif au moins 4 fois le spread observe

## Windows

```powershell
.\scripts\windows\run-scalp-xauusd.ps1
```

Un seul script `run-*.ps1` a la fois. Demo uniquement.
